# Architecture decision records

Use ADRs for decisions that affect multiple modules, milestones, safety
boundaries, persistent schemas, platform support, or externally visible
behavior.

Copy `000-template.md` to the next zero-padded number and a concise slug, for
example `001-android-native-usb-stack.md`. ADRs are immutable after acceptance;
create a later ADR that marks an earlier decision superseded.

Accepted ADRs are required reading for agents working in their affected scope.
